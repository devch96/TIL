# 들어가며

## 코딩을 할 수 있게 된 것일 뿐

```java
Connection conn = ds.getConnection();
try {
    ...
} catch (Exception e) {
        ...
}
// conn.close() 누락
```

- DB 커넥션을 사용한 뒤 풀에 반환하지 않았고 커넥션 누수가 됨
- 풀에 있던 모든 커넥션이 소진되고 풀에서 새로운 커넥션을 가져올 수 없는 오류가 발생함
- 커넥션 누수가 발생하는 버그를 찾아 수정하고 배포함
- 다음 문제는 커넥션의 최대 연결 시간 설정이 없음

-----

- 초보 백엔드 개발자가 몰라서 저지르는 실수는 이 뿐만이 아님
  - 보안에 취약한 코드 작성
  - 급격히 느려지는 시스템을 만들기도 함
- 여러 프레임워크는 서버 개발자가 알아야 할 지식의 일부에 지나지 않음
- 다양한 기초 지식을 모르면 서비스 운영 과정에서 여러 문제가 발생할 수 있음
